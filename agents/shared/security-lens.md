## Security questions

- Who can see each piece of data the change shows, stores or sends, and is that no wider than who could see it before?
- Who can change it, and does the server check every change, rather than the client only hiding it in the UI?
- Which input is trusted? Anything from a request, a URL, a file, a repository or another user is not.
- Does anything secret (tokens, API keys, service secrets, personal data) reach a log, an error message, the client, an agent prompt or a shared link?
