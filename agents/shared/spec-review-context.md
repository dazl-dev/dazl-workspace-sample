## What you review

You review a feature spec in the New Feature workflow. Read `specs/features/<feature-slug>/spec.md` (with its Screens section, if any, and any Fix log) and the existing code the spec touches in `dazl/` and `api-server/`. The run owner agreed this spec in an earlier step. A finding that would reverse an agreed decision must say so, and the spec writer may decline it.
